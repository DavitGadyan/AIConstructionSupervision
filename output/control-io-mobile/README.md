# control.io

Expo (React Native) app generated by `designice scaffold --platform mobile` from the
reference design **ORDI - AI Productivity SaaS, Landing Page + Dashboard** - a desktop web reference, translated for a phone.

```bash
npm install
npx expo install --fix   # aligns every native package to the installed SDK
npx expo start           # scan the QR with Expo Go, or press i / a for a simulator
```

## What is here

Field app for control.io: schedule variance, live drone shots, uploads from the
phone, the 3D model and PDF delay reports. Backend: `../control-io-web` (see its `API.md`).

Set `EXPO_PUBLIC_API_URL` (default `http://localhost:3000`; on a device use your LAN IP).
Demo login `demo@control.io` / `demo1234` is prefilled.

- `app/onboarding.tsx`, `app/login.tsx`, `app/projects.tsx` - first-run flow (gated in `app/(tabs)/_layout.tsx`).
- `app/(tabs)/` - Home, Flights, 3D, Reports, Settings behind the custom floating tab bar (`components/TabBar.tsx`).
- `app/upload.tsx` (modal), `app/shot.tsx` (full-screen shot + metadata).
- `lib/api.ts` REST client + XHR multipart upload; `lib/live.tsx` SSE over `expo/fetch` streaming with
  10 s polling fallback; `lib/session.tsx` token/project in SecureStore (localStorage on web).
- `lib/theme.ts` - every token. Nothing else may hold a colour or a font name.
- `LAYOUT.md` - reference inventory and the mobile derivation table.

## Shipping

`npx expo export` produces a static bundle; `eas build` produces installable binaries.
Neither is needed to iterate - Expo Go runs the project straight from `expo start`.
